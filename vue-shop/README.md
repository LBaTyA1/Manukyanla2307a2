# VueShop — каталог товаров с корзиной (Vue 3 + Vite)

Контрольная работа: интернет-магазин с поиском, фильтрацией, сортировкой и корзиной.

## Запуск

```bash
cd vue-shop
npm i        # установка зависимостей
npm run dev  # запуск на http://localhost:5173
```

## Реализовано

**На «3»**
- каталог товаров (`src/data/products.js`);
- добавление и удаление товаров из корзины, изменение количества (+/−);
- поиск по названию и категории через поле ввода;
- подсчёт итоговой суммы корзины.

**На «4»**
- сортировка по цене (по возрастанию / по убыванию) и по названию;
- фильтр по категории;
- кнопка «Очистить корзину».

**На «5»**
- корзина и применённый промокод сохраняются в `localStorage` — переживают
  обновление страницы;
- промокод `WEB` даёт скидку 10%: пересчитывается цена каждого товара
  (на карточке показывается новая цена, старая зачёркнута, бейдж «−10%»)
  и итоговая сумма корзины.

## Структура

```
vue-shop/
├── index.html                       — точка входа HTML
├── package.json                     — зависимости и скрипты
├── vite.config.js                   — конфиг Vite + алиас '@' на src
└── src/
    ├── main.js                      — создание приложения Vue
    ├── App.vue                      — главный компонент: поиск, фильтр, сортировка
    ├── assets/main.css              — глобальные стили и переменные
    ├── data/products.js             — массив товаров
    ├── composables/useCart.js       — логика корзины, localStorage, промокод
    └── components/
        ├── TheHeader.vue            — шапка со счётчиком товаров
        ├── FiltersPanel.vue         — поиск, категория, сортировка
        ├── ProductCard.vue          — карточка товара
        ├── ProductList.vue          — сетка карточек
        └── ShoppingCart.vue         — корзина, промокод, итоговая сумма
```

## Как заменить эмодзи на картинки

В `src/data/products.js` в поле `image` вместо эмодзи укажите путь к файлу:

```js
{ id: 1, name: 'Ноутбук Pro 14', price: 89990, category: 'Электроника', image: '/img/laptop.png' },
```

Картинки положите в папку `public/img/`. `ProductCard.vue` сам определит,
что в поле лежит путь, и отрисует `<img>` вместо текста.
